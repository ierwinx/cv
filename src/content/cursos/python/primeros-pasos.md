> [!objetivo] Al terminar este módulo sabrás
>
> - Qué es Python, para qué sirve y qué puedes construir con él
> - Instalar Python en Windows, macOS o Linux y comprobar que funciona
> - Usar la terminal para lo básico: moverte por carpetas y ejecutar programas
> - Configurar un editor de código cómodo para trabajar
> - Escribir, guardar y ejecutar tu primer programa
> - Leer un mensaje de error sin asustarte y saber qué hacer con él
