Por qué iPlist

Lo que Xcode no hace por ti con un plist.

Abrir un archivo, cambiar un valor y guardarlo debería ser inmediato y no cambiar nada más. iPlist está hecho para eso, y no intenta ser otra cosa.

Fidelidad total

Abre y guarda un archivo de Xcode sin producir ni un diff.

Se conservan el orden de las claves, las claves duplicadas y el tipo exacto: un integer nunca se convierte en real.

$ git diff --stat Info.plist 0 files changed, 0 insertions(+), 0 deletions(-) $ plutil -lint Info.plist Info.plist: OK
Archivos enormes
640knodos

Un plist de 36 MB abre al instante: solo se crean los nodos que ves.

Todos los formatos

XML, binario y OpenStep.

Cambia entre XML y binario desde la barra al guardar. El cambio también se puede deshacer.

XMLBinarioOpenStep.entitlements.xcprivacy.stringsdict
Deshacer en todo

Cada cambio se puede deshacer.

Renombrar, mover, cambiar un tipo o pegar diez elementos: ⌘Z lo revierte, sin copias del documento.

⌘Z · ⇧⌘Z
Copiar y pegar

Copia como XML, pega donde quieras.

Compatible con Xcode y cualquier editor de texto. También arrastra y suelta elementos entre ventanas.

<key>LSMinimumSystemVersion</key> <string>27.0</string>
Nativo de macOS

Todo lo que esperas de una app de Mac, sin reinventarlo.

Hecha en SwiftUI y Swift 6 sobre el sistema de documentos de macOS 27. Lo que el sistema ya hace bien, iPlist lo usa tal cual.
