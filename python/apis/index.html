🔌 APIs REST

Las dos caras de una API: consumirlas bien, con sus errores y sus límites, y escribirlas con Django REST Framework y con FastAPI, hasta dejarlas documentadas y desplegadas.

📚 30 lecciones ⏱ 480 min en total

Al terminar este módulo sabrás

  • Entender qué es una API REST y cómo se lee su documentación
  • Consumir APIs con la biblioteca estándar y con requests, tratando los errores de verdad
  • Autenticarse con claves, tokens y OAuth, y respetar los límites de uso
  • Convertir los modelos de Django en una API con serializadores, vistas y enrutadores
  • Proteger una API con autenticación por token y permisos por objeto
  • Documentar una API con OpenAPI y probarla entera
  • Conocer FastAPI, saber cuándo elegirlo, y desplegar una API en producción
