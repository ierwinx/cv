🌐 Webs con Django

La misma agenda de contactos del módulo anterior, ahora servida por una web: modelos, vistas, plantillas, formularios, usuarios y puesta en producción.

📚 45 lecciones ⏱ 710 min en total

Al terminar este módulo sabrás

  • Entender qué ocurre entre que alguien escribe una dirección y le llega una página
  • Preparar un entorno virtual e instalar la primera dependencia del curso
  • Guardar los datos con el ORM de Django y hacerlos evolucionar con migraciones
  • Escribir vistas y plantillas, primero con funciones y después con clases
  • Recoger datos con formularios validados y ficheros subidos
  • Registrar usuarios, controlar permisos y aprovechar el panel de administración
  • Dejar el proyecto listo para producción: pruebas, ajustes por entorno, seguridad y despliegue
